CrewRouter 前端设计文档

本文档基于 /data/CrewRouter 项目源码逆向整理，按控件维度系统描述前端设计系统。项目采用 Express.js + PostgreSQL 后端，前端为纯 HTML/CSS/JS，设计风格介于 Linear 的克制与 Raycast 的精致之间：大圆角、多层阴影、玻璃拟态、胶囊导航、点阵背景。

技术栈

类别选型
后端框架Express.js
数据库PostgreSQL
前端纯 HTML / CSS / JavaScript（无框架）
样式CSS 变量 + 原子化布局类
认证OAuth 2.0 / 密码 / 2FA / Passkey
图表Chart.js
图标SF Symbols CDN + 内联 SVG

主题切换

主题状态保存在 localStorage.getItem('theme')，默认 'dark'。每个页面 <head> 中有内联脚本同步读取主题并添加 .light 或 .dark 类到 <html>，防止 FOUC。ThemeManager 在 theme.js 中管理切换，并同步更新 SF Symbol 图标颜色。

<script>
  var theme = localStorage.getItem('theme') || 'dark';
  document.documentElement.classList.add(theme);
</script>

图标说明

项目混用两类图标：

  • SF Symbols：通过 https://img.bloret.net/SF/{name}?color={white|black} 加载 SVG，类名 .sf-icon，随主题自动切换颜色。
  • 内联 SVG：登录页、主题切换按钮、部分操作按钮使用内联 SVG。
function sfIcon(name, size) {
  const color = theme === 'dark' ? 'white' : 'black';
  return `<img src="https://img.bloret.net/SF/${name}?color=${color}" class="sf-icon" />`;
}
