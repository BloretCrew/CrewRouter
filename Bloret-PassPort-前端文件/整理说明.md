# 前端文件整理说明

文件按原项目相对路径保留，均为原文件副本。

- `index.css`：主站样式。
- `index.js`、`minecraft.js`：包含服务端生成的页面 HTML、内联 CSS 和浏览器脚本，也包含大量后端逻辑。
- `ui-i18n-live.js`、`i18n.js`、`lang/`：界面国际化相关代码及语言资源。
- `lib/blora-theme-boot.js`、`lib/blora-message-layer.js`、`management-user-filter.js`：界面主题、消息层和管理页面相关代码。
- `csrf.js`、`lib/recent-auth.js`、`lib/username-compat.js`：包含页面或浏览器脚本片段的混合代码。
- `BL.png`、`icons/` 及 JPG：项目图片资源；`BloretDesign.md` 和 `Docs/UiI18nLive.md` 为相关设计与国际化文档。
- `external-apps/`：仓库中其他项目的前端代码快照，保留原路径；这些是审计用局部快照，并非完整应用，详见其 README。

这是一份前端相关源码整理，不是可独立运行的完整项目。混合文件未拆分，以免破坏原代码。未复制配置、数据库、依赖或日志。
