# 本轮范围与交付

本轮从用户反馈截图建立新原件基线，修正导航、动态图标、资源/统计/表单组合和官方浮层。没有改变服务端接口、权限或数据模型。

工作区先前已有大量未提交 Desktop、Team、Agent 和服务端工作。本轮仅暂存可独立应用的修正；与原有改动重叠的部分保留工作树并交付 turn-patches，边界逐项记录于 partial-staging.json。先前未跟踪的 Desktop launcher 文件保持先前状态，相关本轮改动交付精确补丁。

测试、浏览器和生产构建针对当前工作树。提交自身不包含用户先前全部工作，独立 checkout 的完整端到端运行需先恢复这些既有工作。不会把局部提交描述为已独立发布验收。

初轮 baseline/calibration 用于定位错误，不能作为最终视觉接受记录。正式矩阵及最终定点复验的源码快照、截图和失败分类分别保留。
