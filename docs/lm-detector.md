# 模型归因引擎

模型归因使用 [Ikaleio/lm-detector](https://github.com/Ikaleio/lm-detector)，固定提交 `654c8334bb53951aaf04cbd61252d163649e1369`，本地算法版本为 `lm-detector-shared-v2-crewrouter.1`。

- 浏览器手动模式和服务端任务使用相同的上游共享检测器、位置特征排名及绑定校准数据，当前包含 60 个候选模型。
- 完整置信度要求三条有效回答；一至两条有效回答仅提供未校准排名。不符合上游数字序列特征的回答不生成排名。
- 结果仍是候选库内的闭集比较，不能证明模型身份或认定供应商造假。
- 保留现有授权目标、固定 Key、三次请求预算、费用确认、扣费、取消和历史接口。已有任务保留原算法版本，不重新解释历史结果。
- 不接入上游站点代理，不上传手动回答，不启用额外收费的分词器探测。运行时不需要 Bun、Python 或联网下载模型资源。
- 发布资源包含精简候选元数据、共享检测器及 MIT 许可证，不发布原始回答 JSONL 或采集记录。检测器本身包含上游训练生成的参考特征向量。

## 更新资源

在上游仓库检出固定提交，然后执行：

```sh
node scripts/sync-lm-detector.js /path/to/lm-detector
npm run test:model-trace
```

资源生成脚本使用已有的 esbuild。修改上游版本时，应同步调整脚本、服务端加载器与发布校验器中的提交及算法版本，并重新验证候选库与检测器匹配。所有发布资源均记录 SHA-256，发布和服务端加载时校验；浏览器同时核对候选库与检测器摘要。

为兼容既有路由和桌面打包，静态资源目录继续使用 `public/vendor/modeltrace`，接口继续使用 `/api/model-trace`。
