# 服务端自定义网络目标

Bark 通知与 CPA 管理地址由 CrewRouter 服务端发起请求。服务端会拒绝命中当前拒绝表的私网、回环、链路本地、元数据、多播和部分特殊用途地址，并在每次请求前重新校验；Bark 与 CPA 请求均不跟随重定向。

确实需要连接私有服务时，可在 CrewRouter 服务进程环境中配置精确主机允许列表：

- `CR_BARK_PRIVATE_ORIGINS`：允许的私有 Bark origin。
- `CR_CPA_PRIVATE_ORIGINS`：允许的私有 CPA origin。

列表使用逗号分隔，必须写完整 origin，包含协议、主机和端口，例如 `http://127.0.0.1:8317`；不支持通配符、CIDR 或路径。IPv6 遵循 URL 格式，例如 `http://[::1]:8317`。新增或修改环境变量后重启 CrewRouter 服务。只允许实际需要的目标；允许某个 DNS origin 也意味着该名称可解析到的私有地址会被信任。

Bark 和 CPA 的公网地址必须使用 HTTPS。只有精确列入对应允许列表的 origin 才可使用 HTTP，以兼容本机或内网服务。

DNS 校验与后续连接仍存在时间差，允许列表也不能替代出站网络控制。应在主机或容器网络层禁止应用访问未授权的私网和云元数据地址。
