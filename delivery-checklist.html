项目说明
系统要求 Node.js ≥ 16（推荐 20 LTS）、PostgreSQL ≥ 14、内存 ≥ 2 GB、磁盘 ≥ 1 GB
首次部署流程 ① 安装 Node.js + PostgreSQL → ② 上传程序 → ③ 安装依赖 → ④ 配置数据库 → ⑤ 启动 → ⑥ 浏览器访问初始化向导 → ⑦ 创建管理员账户 → ⑧ 配置 AI 供应商
运维管理 systemd 开机自启（直接运行） / Docker 自动重启策略。日志位于 log/ 目录，无自动轮转需自行配置 logrotate
备份策略 核心数据在 PostgreSQL 数据库中。备份命令：pg_dump -U crewrouter crewrouter > backup.sql
更新升级 直接运行：替换 dist/ 文件 → npm install --omit=dev → 重启服务。Docker：docker compose pull && docker compose up -d
数据安全 建议使用 Nginx 反向代理 + Let's Encrypt（certbot）配置 HTTPS。数据库端口（5432）不应暴露公网
