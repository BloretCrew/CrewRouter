代理设置

配置系统级代理地址（HTTP / HTTPS / SOCKS4 / SOCKS5）。默认不对全部流量生效；可勾选下方选项让所有上游连接走代理，或仅在供应商中单独开启。

示例：http://user:pass@host:port、https://host:port、socks5://host:1080、socks5h://host:1080。供应商勾选「使用系统代理」时使用此地址，无需开启下方全局选项。
开启后，所有供应商的上游请求均走上方代理。关闭时，仅在供应商管理中单独启用代理的供应商会走代理（可填自定义地址或引用本页代理地址）。

代理池设置

全局代理池配置，供应商编辑中选择「代理池」模式并启用后自动生效。支持 IP 限速时自动切换代理。

供应商识别的模型名称，同一供应商下不可重复，不同供应商可使用相同模型名
设置别名后，用户将通过别名请求模型，供应商仍使用原始上游模型名
系列名称将显示在用户控制台，用于分类筛选模型
倍率设置
倍率控制模型请求的积分消耗速度。1 积分 = 1,000,000 加权 Token。
加权 Token = (输入Token + 缓存输入×0.1 + 输出Token) × 倍率
模型越贵倍率越高。例如 GPT-4 设为 10，GPT-3.5 设为 1
模型路由（可选，用于根据思考模式自动切换模型）

关闭思考模式时实际使用的模型

添加供应商

同一供应商可重复添加。点击查询可按名称自动填充 Base URL 等信息。
最上方为主 Key（获取模型列表 / 连通性 / 额度仅用主 Key）。多个 Key 时可拖动排序。 顺序模式：调用时按排序依次 fallback；权重模式：按权重随机选 Key，失败后再按权重从高到低 fallback。 编辑时修改 Key 文本即更新；留空该项在保存时会被忽略。
密钥模式 固定密钥 / 脚本刷新
📖 脚本开发文档（点击展开）
执行方式：脚本被包装为 async function(ctx) 执行
上下文变量 ctx：
ctx.baseUrl供应商 Base URL（已去除尾部 /）
ctx.providerId供应商 ID
ctx.providerName供应商名称
ctx.currentKey当前缓存的密钥（首次刷新时为空）
ctx.fetch全局 fetch 函数，可直接发 HTTP 请求
返回值：
① 直接返回密钥字符串：return 'sk-xxx'
② 返回对象：return { key: 'sk-xxx', expiresIn: 3600 }
expiresIn 单位为秒。支持别名：access_token、token、expires_in
错误处理：
脚本抛出异常时，系统保留旧密钥并在 60 秒后重试。
💡 快速示例：
最少 60 秒。脚本返回 expiresIn 时会覆盖此值
