概览与认证

Base URL

https://studio.crantai.com/v1

认证方式

在请求 Header 中携带 API Key：

Authorization: Bearer YOUR_API_KEY

或使用自定义 Header：

X-API-Key: YOUR_API_KEY

快速示例

使用 OpenAI SDK 直接接入：

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-xxx',
  baseURL: 'https://studio.crantai.com/v1'
});

const res = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});

聊天补全 (Chat Completions)

POST /v1/chat/completions

完全兼容 OpenAI SDK 和 API 格式。

请求参数

参数类型必填说明
modelstring是模型 ID
messagesarray是消息数组
streamboolean否是否流式输出（默认 false）
temperaturenumber否温度参数（0-2）
max_tokensinteger否最大生成 token 数
thinkingboolean否DeepSeek 思考模型是否启用思考（默认 true）

非流式请求示例

curl -X POST https://studio.crantai.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxx" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'

流式输出 (SSE)

设置 "stream": true，服务端返回 Server-Sent Events：

data: {"choices":[{"delta":{"content":"Hi"},"index":0}]}
data: {"choices":[{"delta":{"content":" there"},"index":0}]}
data: {"choices":[{"delta":{"content":"!"},"index":0}]}
data: [DONE]

模型列表

GET /v1/models

返回所有已启用模型的列表，兼容 OpenAI 格式。

curl https://studio.crantai.com/v1/models \
  -H "Authorization: Bearer sk-xxx"

支持的模型

Anthropic 兼容接口

POST /v1/messages

兼容 Anthropic Claude API 格式，底层自动转换。

请求参数

参数类型必填说明
modelstring是模型 ID
max_tokensinteger是最大生成 token 数
messagesarray是消息数组
systemstring否系统提示词
streamboolean否是否流式输出

请求示例

curl -X POST https://studio.crantai.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-xxx" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
