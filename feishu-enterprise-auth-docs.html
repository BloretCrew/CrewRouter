核心原理

通过 飞书 OAuth 2.0 登录 实现企业内用户隔离注册。系统核心逻辑如下：

用户点击
飞书登录
→
跳转飞书
授权页面
→
用户扫码
确认授权
→
返回站点
获取 code
→
校验 tenant_key
& 邮箱域名
→
发放 JWT
完成注册

Tenant Key 是飞书企业的唯一标识，相当于企业的「身份证号」。校验此字段即可确保只有特定企业员工能注册。

OAuth 授权流程详解

步骤 动作 说明
1 生成授权链接 后端拼接 app_id、redirect_uri、state
2 用户授权 用户在飞书端扫码或点击确认授权
3 获取 Code 飞书重定向到 redirect_uri?code=xxx&state=xxx
4 换取 Token 用 code 调用飞书接口换取 access_token
5 获取用户信息 用 access_token 获取用户 open_id、tenant_key、邮箱等
6 企业校验 比对 tenant_key 和邮箱域名白名单
7 发放凭证 生成 JWT，重定向回前端完成登录

安全要点

安全措施 作用 优先级
Tenant Key 校验 核心隔离手段，确保只有目标企业员工能登录 必须
邮箱域名白名单 双重保险，防止 tenant_key 异常时的兜底 强烈建议
State 参数校验 防止 CSRF 攻击 必须
JWT 过期时间 Token 设置合理过期时间（建议 7 天） 强烈建议
HTTPS 传输 生产环境必须启用，防止中间人攻击 必须
App Secret 保护 绝不暴露在前端，使用环境变量管理 必须

飞书应用配置

在 飞书开放平台 创建企业自建应用：

  1. 创建应用
    进入「开发者后台」→「创建企业自建应用」→ 选择「企业自建应用」类型
    内部使用 无需上架审核
  2. 配置权限
    进入「权限管理」，添加以下权限：
    • contact:user.employee_id:readonly — 获取用户员工 ID
    • contact:user.base:readonly — 获取用户基础信息
    • auth:user.id:readonly — 获取用户 ID 信息
  3. 配置登录设置
    进入「登录与分享」→ 添加 Web 应用安全域名（你的站点域名，如 https://your-site.com）
  4. 配置重定向 URL
    添加回调地址：https://your-site.com/api/auth/feishu/callback
    ⚠️ 必须与后端配置的 redirect_uri 完全一致，包括协议和路径
  5. 发布应用
    进入「版本管理与发布」→ 创建版本 → 申请发布 → 管理员审批通过
注意：应用未发布时，只有应用创建者能测试。如需多人测试，在「成员管理」中添加测试人员。

如何获取 Tenant Key

Tenant Key 是你的企业在飞书中的唯一标识，有以下几种获取方式：

方式一：通过飞书管理后台查看

  1. 登录飞书管理后台（https://www.feishu.cn/admin）
  2. 进入「企业设置」→「企业信息」
  3. 查看「企业编号」，即为 Tenant Key

方式二：通过 API 获取

调用飞书接口，在返回的用户信息中会包含 tenant_key：

curl -X GET 'https://open.feishu.cn/open-apis/authen/v1/user_info'   -H 'Authorization: Bearer {access_token}'

方式三：临时打印调试

在开发阶段，可以临时关闭 tenant_key 校验，先打印出登录用户的 tenant_key，确认后再配置到环境变量中。

// 飞书应用级 Access Token 缓存

let appAccessToken = null;
let tokenExpireTime = 0;

async function getAppAccessToken() {
  // 如果 token 未过期，直接返回缓存
  if (appAccessToken && Date.now() < tokenExpireTime) {
    return appAccessToken;
  }

  try {
    const res = await axios.post(
      'https://open.feishu.cn/open-apis/auth/v3/app_access_token/internal',
      {
        app_id: CONFIG.FEISHU_APP_ID,
        app_secret: CONFIG.FEISHU_APP_SECRET
      }
    );

    if (res.data.code !== 0) {
      throw new Error(`获取 App Access Token 失败: ${res.data.msg}`);
    }

    appAccessToken = res.data.app_access_token;
    // 提前 5 分钟刷新
    tokenExpireTime = Date.now() + (res.data.expire - 300) * 1000;

    return appAccessToken;
  } catch (error) {
    console.error('获取 App Access Token 失败:', error.message);
    throw error;
  }
}

// 步骤 1：生成飞书授权链接

app.get('/api/auth/feishu', (req, res) => {
  const redirectUri = encodeURIComponent(
    `${req.protocol}://${req.get('host')}/api/auth/feishu/callback`
  );

  // 生成随机 state，防止 CSRF
  const state = Math.random().toString(36).substring(2, 15) + 
                Math.random().toString(36).substring(2, 15);

  req.session.oauthState = state;
  req.session.save();

  const authUrl = `https://open.feishu.cn/open-apis/authen/v1/authorize?` +
    `app_id=${CONFIG.FEISHU_APP_ID}` +
    `&redirect_uri=${redirectUri}` +
    `&state=${state}`;

  res.json({ 
    success: true,
    authUrl 
  });
});

// ========================================
// 步骤 2：处理飞书回调
// ========================================
app.get('/api/auth/feishu/callback', async (req, res) => {
  const { code, state } = req.query;

  // 校验 state 防止 CSRF 攻击
  if (!state || state !== req.session.oauthState) {
    console.warn('State 校验失败，可能存在 CSRF 攻击');
    return res.redirect(`${CONFIG.FRONTEND_URL}/login?error=invalid_state`);
  }

  // 清除 session 中的 state
  req.session.oauthState = null;

  if (!code) {
    return res.redirect(`${CONFIG.FRONTEND_URL}/login?error=no_code`);
  }

  try {
    // -------- 2.1 用 code 换取 access_token --------
    const tokenRes = await axios.post(
      'https://open.feishu.cn/open-apis/authen/v1/oidc/access_token',
      {
        grant_type: 'authorization_code',
        code: code
      },
      {
        headers: {
          'Authorization': `Bearer ${await getAppAccessToken()}`,
          'Content-Type': 'application/json'
        }
      }
    );

    if (tokenRes.data.code !== 0) {
      throw new Error(tokenRes.data.msg);
    }

    const accessToken = tokenRes.data.data.access_token;

    // -------- 2.2 获取用户信息 --------
    const userRes = await axios.get(
      'https://open.feishu.cn/open-apis/authen/v1/user_info',
      {
        headers: { 
          'Authorization': `Bearer ${accessToken}` 
        }
      }
    );

    if (userRes.data.code !== 0) {
      throw new Error(userRes.data.msg);
    }

    const userInfo = userRes.data.data;

    console.log('飞书用户登录:', {
      name: userInfo.name,
      email: userInfo.email,
      tenant_key: userInfo.tenant_key,
      employee_id: userInfo.employee_id
    });

    // ========================================
    // 关键校验 1：Tenant Key 企业隔离
    // ========================================
    if (userInfo.tenant_key !== CONFIG.ALLOWED_TENANT_KEY) {
      console.warn(
        `拒绝非企业员工登录: ${userInfo.email}, ` +
        `tenant: ${userInfo.tenant_key}, ` +
        `期望: ${CONFIG.ALLOWED_TENANT_KEY}`
      );
      return res.redirect(
        `${CONFIG.FRONTEND_URL}/login?error=not_enterprise_user`
      );
    }

    // ========================================
    // 关键校验 2：邮箱域名白名单（双重保险）
    // ========================================
    const emailDomain = userInfo.email?.split('@')[1];
    if (!emailDomain || !CONFIG.ALLOWED_DOMAINS.includes(emailDomain)) {
      console.warn(
        `拒绝非企业邮箱: ${userInfo.email}, ` +
        `域名: ${emailDomain}`
      );
      return res.redirect(
        `${CONFIG.FRONTEND_URL}/login?error=invalid_domain`
      );
    }

    // ========================================
    // 2.3 查找或创建用户
    // ========================================
    const user = await findOrCreateUser({
      feishuOpenId: userInfo.open_id,
      feishuUnionId: userInfo.union_id,
      employeeId: userInfo.employee_id,
      tenantKey: userInfo.tenant_key,
      name: userInfo.name,
      email: userInfo.email,
      avatar: userInfo.avatar_url,
      department: userInfo.department
    });

    // ========================================
    // 2.4 生成 JWT Token
    // ========================================
    const token = jwt.sign(
      { 
        userId: user.id,
        email: user.email,
        tenantKey: user.tenantKey,
        employeeId: user.employeeId
      },
      CONFIG.JWT_SECRET,
      { expiresIn: '7d' } // Token 7 天有效
    );

    // 重定向到前端，通过 URL 参数传递 token
    // 生产环境建议使用 httpOnly cookie 更安全
    res.redirect(`${CONFIG.FRONTEND_URL}/auth/callback?token=${token}`);

  } catch (error) {
    console.error('飞书登录失败:', error.response?.data || error.message);
    res.redirect(`${CONFIG.FRONTEND_URL}/login?error=auth_failed`);
  }
});

认证中间件

/**
 * JWT 认证中间件
 * 验证请求头中的 Authorization: Bearer 
 */
const authenticate = (req, res, next) => {
  const authHeader = req.headers.authorization;

  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ 
      success: false, 
      error: '未提供认证令牌' 
    });
  }

  const token = authHeader.split(' ')[1];

  try {
    const decoded = jwt.verify(token, CONFIG.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    if (error.name === 'TokenExpiredError') {
      return res.status(401).json({ 
        success: false, 
        error: '登录已过期，请重新登录' 
      });
    }
    return res.status(401).json({ 
      success: false, 
      error: '无效的认证令牌' 
    });
  }
};

/**
 * 企业成员校验中间件
 * 确保用户属于允许的企业
 */
const requireEnterpriseMember = (req, res, next) => {
  if (req.user.tenantKey !== CONFIG.ALLOWED_TENANT_KEY) {
    return res.status(403).json({
      success: false,
      error: '无权访问，仅限企业内部成员'
    });
  }
  next();
};

AuthCallback.jsx — 处理登录回调

import React from 'react';
import { useSearchParams, useNavigate } from 'react-router-dom';

function AuthCallback() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();
  const [status, setStatus] = React.useState('processing');

  React.useEffect(() => {
    const token = searchParams.get('token');
    const error = searchParams.get('error');

    if (error) {
      setStatus('error');
      setTimeout(() => navigate(`/login?error=${error}`), 1500);
      return;
    }

    if (token) {
      // 存储 Token（生产环境建议使用 httpOnly cookie）
      localStorage.setItem('token', token);

      // 可选：解析 JWT 获取基本信息
      try {
        const payload = JSON.parse(atob(token.split('.')[1]));
        localStorage.setItem('userInfo', JSON.stringify({
          userId: payload.userId,
          email: payload.email
        }));
      } catch (e) {
        console.error('解析 Token 失败:', e);
      }

      setStatus('success');
      setTimeout(() => navigate('/dashboard'), 1000);
    } else {
      setStatus('error');
      setTimeout(() => navigate('/login?error=auth_failed'), 1500);
    }
  }, [searchParams, navigate]);

  const statusConfig = {
    processing: { icon: '⟳', text: '登录处理中...', color: '#3370ff' },
    success: { icon: '✅', text: '登录成功，正在跳转...', color: '#10b981' },
    error: { icon: '❌', text: '登录失败，正在返回...', color: '#ef4444' }
  };

  const current = statusConfig[status];

  return (
    

      
{current.icon}

      

        {current.text}
      

    

  );
}

export default AuthCallback;

 * 受保护路由组件
 * 检查本地存储的 JWT 是否有效

      setIsAuthenticated(false);

    fetch('/api/me', {
      headers: { 
        'Authorization': `Bearer ${token}` 
      }
    })
    .then(res => {
      if (!res.ok) {
        // Token 无效或过期，清除存储
        localStorage.removeItem('token');
        localStorage.removeItem('userInfo');
        setIsAuthenticated(false);
        return null;
      }
      return res.json();
    })
    .then(data => {
      if (data && data.success) {
        setUser(data.user);
        setIsAuthenticated(true);
      }
    })
    .catch(() => {
      localStorage.removeItem('token');
      setIsAuthenticated(false);
    });
  }, []);

  }

  if (!isAuthenticated) {
    return ;
  }

  // 将用户信息传递给子组件
  return React.cloneElement(children, { user });
}
